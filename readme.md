# Resting State Paradigm

A PsychoPy-based resting state paradigm for M/EEG recordings. The task collects brain activity across three phases: artifact recordings, eyes-open resting state, and eyes-closed resting state. Instructions are presented in German.

## Task Overview

### 1. Artifact Recordings (optional)

Participants perform five common M/EEG artifact movements so that these signals can later be identified and removed from the resting state data:

| # | Artifact         | Instruction (German)                                   |
|---|------------------|--------------------------------------------------------|
| 1 | Eye rolling      | Augen rollen                                           |
| 2 | Eye blinking     | Blinzeln                                               |
| 3 | Eye saccades     | Augen hin und her bewegen                              |
| 4 | Teeth grinding   | Kiefer anspannen und mit den Zähnen knirschen          |
| 5 | Swallowing       | Mehrfach hintereinander schlucken                      |

Each artifact is preceded by a 3-second countdown. This phase can be toggled on/off in the participant dialog.

### 2. Eyes-Open Resting State (5 min)

Participants fixate a central cross on the screen for 5 minutes while sitting quietly and relaxed.

### 3. Eyes-Closed Resting State (5 min, optional)

Participants close their eyes when they hear a **high-pitched tone (660 Hz, 1 s)** at the start of the recording and open them again when they hear a **low-pitched tone (220 Hz, 1 s)** at the end. This phase can be toggled on/off in the participant dialog.

## Versions

Two versions of the task are provided for compatibility with different PsychoPy installations:

| File                       | PsychoPy Version | Python   | Audio Library  | Window Size |
|----------------------------|------------------|----------|----------------|-------------|
| `resting_task_v2026.psyexp` | 2026.1.1         | >= 3.10  | ptb (PsychToolbox) | 1024 x 768  |
| `resting_task_v2021.psyexp` | 2021.2.2         | >= 3.8   | pyo            | 1920 x 1080 |

Each `.psyexp` file has a corresponding `.py` script that was auto-generated by the PsychoPy Builder.

## Directory Structure

```
Resting_Paradigm/
├── resting_task_v2026.psyexp      # Current experiment (PsychoPy Builder)
├── resting_task_v2026.py          # Auto-generated Python script (v2026)
├── resting_task_v2021.psyexp      # Legacy experiment (PsychoPy Builder)
├── resting_task_v2021.py          # Auto-generated Python script (v2021)
├── instructions/                  # Instruction text loaded during the task
│   ├── artifact_instruction.csv   # Artifact recording instructions (5 items)
│   ├── eyesopen_instruction.csv   # Eyes-open instructions (2 slides)
│   └── eyesclosed_instruction.csv # Eyes-closed instructions (1 slide)
├── data/                          # Participant data output (excluded from repo)
└── readme.md
```

## Requirements

- [PsychoPy](https://www.psychopy.org/) (v2026.1.1 recommended, v2021.2.2 for legacy)
- Python >= 3.10 (or >= 3.8 for the legacy version)

## How to Run

1. Install PsychoPy (standalone installer or via pip).
2. Open the appropriate `.psyexp` file in PsychoPy Builder:
   - `resting_task_v2026.psyexp` for PsychoPy >= 2026.1.1
   - `resting_task_v2021.psyexp` for PsychoPy 2021.2.2
3. Adjust the presentation modalities (screen size or full screen etc.) according to your setup. Also adjust the trigger presentations according to your setup (see section Trigger).
4. Click the **Run** button in the Builder, or run the corresponding `.py` script directly.
5. Fill in the participant dialog:

   | Field                  | Description                                | Default    |
   |------------------------|--------------------------------------------|------------|
   | participant            | Participant ID                             |            |
   | gender                 | Participant gender                         | `f`        |
   | date_of_birth          | Date of birth (DD.MM.YYYY)                 |            |
   | ethnicity              | Participant ethnicity                      |            |
   | diagnosis              | Clinical group label                       | `control`  |
   | artifact_recording     | Run artifact phase (1 = yes, 0 = no)       | `1`        |
   | eyesclosed_recording   | Run eyes-closed phase (1 = yes, 0 = no)    | `1`        |

6. Data files are saved to the `data/` folder with the naming convention:
   ```
   data/<participant>_resting_task_<version>_<phases>_<date>
   ```
   where `<phases>` encodes which phases were run:
   - `eyeop_eyecl`: recording also contains an eyes closed part
   - `eyeop_artfrec`: recording also contains an artifact recording
   - `eyeop_eyecl_artfrec`: reording contains all parts

## Customization

- **Instructions**: Edit the CSV files in `instructions/` to change instruction text or add slides. The task loads these dynamically so no code changes are needed.
- **Recording duration**: Modify the duration of the eyes-open and eyes-closed routines in the PsychoPy Builder (default: 300 s each).
- **Tone parameters**: The start/stop tones for the eyes-closed phase can be adjusted in the Builder (frequency, duration, volume).
- **Window size**: Set in the Experiment Settings dialog within the Builder.
